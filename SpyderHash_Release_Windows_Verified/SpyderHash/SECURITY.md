# Security and responsible use

SpyderHash performs offline **format inspection only**. It does not crack credentials, collect passwords or contact external servers.

- Use the tool only on data you are authorized to examine.
- Avoid adding real password hashes, credentials or other sensitive samples to public repositories.
- Do not interpret a format match as proof of an algorithm, a valid encoded hash, or the identity of a user.
- Do not paste sensitive input into public issue reports. Report potential security bugs to the maintainer privately.
- The batch mode intentionally imposes limits on input line count and value length.
